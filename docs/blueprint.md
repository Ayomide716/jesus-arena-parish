# **App Name**: Optical Clarity

## Core Features:

- File Upload: Upload image (PNG, JPG) or PDF files for text extraction.
- Text Extraction: Initiate the OCR process to extract text from the uploaded file.
- Editable Display: Display the extracted text in an editable text field, allowing users to correct errors.
- Copy/Download Text: Provide options to copy the extracted text to the clipboard or download it as a text file.

## Style Guidelines:

- Primary color: Professional blue (#29ABE2) for trust and clarity.
- Background color: Clean white (#F9F9F9) for a professional and distraction-free interface.
- Accent color: Light blue (#BBDEFB) for interactive elements and highlights.
- Body and headline font: 'Inter' sans-serif for a modern, clean, objective feel; well-suited for both headlines and body text.
- Use simple, clear icons to represent actions like upload, extract, copy, and download.
- Maintain a clean and organized layout with clear visual hierarchy, ensuring ease of use.
- Incorporate subtle animations, such as progress bars during text extraction, to enhance user experience.
